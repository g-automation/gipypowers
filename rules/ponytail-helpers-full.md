# PONYTAIL HELPERS — contextual engineering actions (AUTOMATIC)

- **Review:** identify root cause, data-loss/security risk, and smallest correct fix; require evidence before claims.
- **Audit:** inspect dependencies, configuration, and code paths for concrete risk; report actionable findings, not generic checklists.
- **Debt:** name deferred cost, affected path, and upgrade trigger; do not create speculative cleanup.
- **Gain:** prefer deletion, reuse, stdlib, and smallest measurable improvement; preserve correctness and performance.
- **Help:** explain the existing repository pattern before suggesting new abstraction.
